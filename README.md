🌦️ Weather Dashboard

A responsive Weather Dashboard built using HTML, CSS, and JavaScript that displays real-time weather information and a 5-day forecast for any searched city.

🌐 Live Demo

Click here to view Weather Dashboard
https://wahidshaikh0787-byte.github.io/Weather-Dashboard/)
🚀 Features

Search weather by city name

Real-time weather data using Open-Meteo API

Current temperature and weather conditions

Wind speed, humidity, and precipitation details

5-day weather forecast

Dark mode and light mode

Celsius and Fahrenheit temperature toggle

Recent searches saved using Local Storage

Responsive design for different screen sizes

Loading indicator and error handling

🛠️ Technologies Used

HTML5

CSS3

JavaScript

Fetch API

Open-Meteo Weather API

Local Storage

⚙️ How to Run Locally

Download or clone this repository.

Open the project folder in VS Code.

Open index.html in your browser.

Search for any city to view its weather information.

🌍 API Used

This project uses the Open-Meteo API to fetch weather information.

API Website: https://open-meteo.com/

No API key is required.

🎯 Project Objective

The main objective of this project is to understand and implement JavaScript concepts such as Fetch API, asynchronous programming, DOM manipulation, error handling, and Local Storage while building a practical weather application.
